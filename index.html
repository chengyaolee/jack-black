2. Running Count vs True Count

Running Count (RC): Every card dealt face-up adds or subtracts from your mental count. Note: in real casinos, the dealer's face-down card is not counted until revealed!

True Count (TC): Because high cards are spread across multiple decks, divide the Running Count by the estimated decks remaining in the shoe:

True Count = Running Count ÷ Decks Remaining

Example: If the Running Count is +8 and there are 2 decks remaining, the True Count is +4.

3. The Bet Spread (Ramping Your Bets)

  • TC ≤ +1: Casino holds edge. Bet table minimum ($10).
  • TC = +2: Slight player edge (~+0.5%). Ramp bet to 2x ($20).
  • TC = +3: Strong edge (~+1.0%). Ramp bet to 4x ($40).
  • TC ≥ +4: Hot shoe! (~+1.5% to +2.5%). Ramp bet to 6x–8x ($60–$80+).

4. Key Strategy Deviations (Illustrious 18)

  • Insurance: Take insurance ONLY if True Count ≥ +3.
  • 16 vs Dealer 10: Stand if True Count ≥ 0 (normally Hit).
  • 15 vs Dealer 10: Stand if True Count ≥ +4 (normally Hit).
  • 12 vs Dealer 3: Stand if True Count ≥ +2 (normally Hit).
  • 12 vs Dealer 2: Stand if True Count ≥ +3 (normally Hit).
